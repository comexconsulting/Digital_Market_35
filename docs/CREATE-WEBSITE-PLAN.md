# Create Website Plan

## Context
- Started: 2026-08-02
- Marca: **Digital_Market_35** — agencia de IA para empresas.
- Servicios: webs, CRMs, chatbots, automatizaciones.
- Objetivo primario de conversión: agendar demo/llamada.
- Alcance: landing de una sola página (no multi-página).
- Stack: React + TypeScript + Tailwind CSS + Framer Motion + Lucide React (mismo stack que la referencia "Jack — 3D Creator").
- Nivel de craft: máximo impacto visual — motion-heavy (hero cinematográfico, efecto magnético, scroll reveals, marquee), inspirado en el prompt de referencia "Jack — 3D Creator".
- Prueba social: agencia nueva, sin testimonios/casos todavía. Se reemplaza por: proceso de trabajo transparente, stack tecnológico concreto, disponibilidad/tiempos de respuesta, garantías reales (a definir en Fase 8) — nunca testimonios inventados.
- Referencias de estilo:
  - **Estética futurista (screenshots del usuario, resuelto):** fondo oscuro casi negro con iluminación cinematográfica; robots/androides con detalles metálicos y ojos/acentos que brillan en ámbar-naranja; paneles holográficos translúcidos tipo HUD (glassmorphism) en cian/teal con iconos de nube, gráficos de barras, dashboards y streams de código/datos superpuestos sobre la escena; líneas de luz curvas naranjas conectando elementos; oficinas nocturnas con vidrio y skyline desenfocado de fondo; tipografía de captions en blanco grueso, sin serif. Paleta core: negro/gris oscuro + cian-teal (datos/tech) + ámbar-naranja (acento/energía). Sensación: IA de alta gama, cinematográfica, con profundidad (paneles flotando delante del fondo), no un gradiente plano genérico "AI purple-to-blue".
  - Estructura de referencia (solo esqueleto/lógica, no clonar): https://duclosdesign.com.ar/diseno-web-cordoba/ — hero con métricas, sección de valor diferencial, auditoría/prueba visual, problemas resueltos, tarjetas de tipos de servicio, proceso en pasos numerados, qué incluye, testimonios, FAQ, CTA final con WhatsApp.
  - Prompt de diseño detallado "Jack — 3D Creator": hero fullscreen con heading gigante gradiente, marquee de imágenes scroll-driven, sección about con texto animado carácter a carácter, servicios en lista numerada, proyectos en cards sticky-stacking. Se traslada la calidad de interacción, no el contenido literal.
